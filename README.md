# Multi-threaded HTTP Server with User Auth (C++17)

Многопоточный HTTP-сервер на C++17 под Windows (Winsock2) с реализованной системой регистрации/авторизации пользователей, встроенным тред-пулом и простым файловым хранилищем.

## 🚀 Основные возможности

* **Собственный ThreadPool:** Эффективное распределение поступающих клиентских подключений по рабочим потокам без оверхеда на частый сокет-диспатчинг.
* **Сетевой стек на Winsock2:** Низкоуровневая обработка TCP-сокетов (`SOCK_STREAM`), парсинг протокола HTTP/1.1 (GET/POST-запросы).
* **Аутентификация и безопасность:**
  * Регистрация и вход пользователей с валидацией имени (только латиница, цифры и `_`).
  * Хэширование паролей с уникальной солью (Salt) для каждого пользователя (алгоритм FNV-1a).
  * Потокобезопасная база данных в памяти (`std::unordered_map` + `std::mutex`) с персистентным сохранением на диск в `users_db.txt`.
* **Парсинг HTTP:** Извлечение заголовочных полей (case-insensitive), тел запросов (`application/x-www-form-urlencoded`) и данных о клиенте (IP, порт, User-Agent).
* **Встроенные HTML-страницы:** Рендеринг форм авторизации/регистрации и личного кабинета непосредственно из C++ шаблонов.

## 🛠 Сборка и запуск

### Требования
* Операционная система: **Windows**
* Компилятор C++ с поддержкой **C++17** (MSVC / GCC / Clang)
* Библиотека **Winsock2** (`ws2_32.lib`)

### Сборка через MSVC (Developer Command Prompt / Visual Studio)
